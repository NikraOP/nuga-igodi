# Нуга & Ягоды — свадебные торты

Статический сайт на HTML, CSS и JavaScript. Сборка не требуется.

Основные файлы: `index.html`, `css/style.css`, `js/main.js`. Изображения и шрифты находятся в `assets/`. Политика конфиденциальности — `privacy.html`.

Чтобы запустить локальный предпросмотр, используйте любой статический HTTP-сервер из корня репозитория. Не открывайте `index.html` как локальный файл: браузер может не загрузить часть ресурсов.
